# Focus Milestone

맥에서 쓰는 작은 뽀모도로 집중 앱입니다. 사진 속 아날로그 주방 타이머처럼 사각 다이얼과 빨간 진행 영역을 중심에 두고, 오른쪽에서 오늘의 목표와 체크리스트를 관리합니다.

## Ver 0.0.1

윈도우 버전을 배포합니다.

## 실행 앱 만들기

```bash
bash Scripts/build_app.sh
```

완성된 앱은 `build/FocusMilestone.app`에 생성됩니다.

## 기능

- 집중/휴식 시간을 조절하는 뽀모도로 타이머
- 목표 라운드 수와 완료 라운드 표시
- 오늘의 목표 입력
- 체크리스트 추가, 완료, 삭제
- 목표와 체크리스트 자동 저장
- 세션 종료 시 다음 단계 자동 전환 및 시스템 비프음

## 개선점
- 타이머 색상 설정
- 라이트 / 다크 모드 만들기
- dmg 배포 작업 하기
- 윈도우 버전 레이아웃 오류 수정
